How to read this view

The residual vector for step t belongs to the query position used to predict generated token t. The attention row shows where a conventional full-attention block reads from that query. Linear-attention blocks do not yield comparable softmax rows in this capture. Routing and activation magnitude are observational; tracing causal influence requires controlled patching or ablation.
